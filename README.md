# 🔐 Sistema de Autenticação

Sistema de autenticação desenvolvido com foco em **segurança, controle de acesso e múltiplos métodos de autenticação**.

## 🚀 Funcionalidades

* JWT
* Refresh Token
* OAuth 2.0 com Google
* Recuperação de senha
* Verificação de e-mail
* RBAC (Admin, User...)

## 🛠️ Tecnologias

* TypeScript
* Node.js
* NestJS
* JWT
* OAuth 2.0
* Google OAuth
* Nodemailer

## 📌 Status

**Concluído.**

O sistema possui autenticação baseada em **JWT**, suporte a **Refresh Token**, login através do **Google OAuth**, recuperação de senha, verificação de e-mail e controle de acesso baseado em funções (RBAC).

## 📂 Objetivo

Desenvolver um sistema de autenticação **completo, seguro e escalável**, oferecendo diferentes métodos de autenticação e gerenciamento de permissões de usuários.
