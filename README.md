# 🔐 Sistema de Autenticação

Sistema de autenticação desenvolvido com foco em segurança, controle de acesso e diferentes métodos de login.

## 🚀 Funcionalidades

- [x] JWT
- [ ] Refresh Token
- [x] OAuth com Google
- [x] Recuperação de senha
- [x] Verificação por e-mail
- [ ] RBAC (Admin, User...)

## 🛠️ Tecnologias

- TypeScript
- Node.js
- NestJS
- JWT
- OAuth 2.0
- Google OAuth

## 📌 Status

O projeto está em desenvolvimento.

Atualmente, o sistema conta com autenticação utilizando **JWT** e login através do **Google OAuth**. As demais funcionalidades serão implementadas gradualmente.

## 📂 Objetivo

Criar um sistema de autenticação completo, seguro e escalável, com suporte a diferentes métodos de autenticação e gerenciamento de permissões.
